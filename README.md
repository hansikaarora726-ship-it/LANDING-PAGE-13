## 📌 Project Overview
This project is a modern and attractive landing page created using HTML and CSS. It features a navigation bar, hero section, feature cards, call-to-action section, and footer.

## ✨ Features
- Clean and modern user interface
- Navigation bar with section links
- Hero section with heading, description, and button
- Features section with three feature cards
- Call-to-action section
- Hover effects on buttons and cards
- Pastel purple colour theme
- Responsive layout for desktop, tablet, and mobile devices

## 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## 🚀 How to Run the Project
1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in a web browser.
4. Explore the different sections of the landing page.

## 📱 Responsive Design
The webpage adjusts to different screen sizes using CSS media queries:
- Desktop: Side-by-side hero section and three-column feature layout.
- Tablet: Adjusted font sizes and feature grid.
- Mobile: Stacked hero section and single-column feature cards.
